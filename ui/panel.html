Usage

  • Open Visual Library from the chat right sidebar.
  • Import an image URL or supported page URL into This Chat, the current Campaign, or the Global library.
  • Use Show in Chat on any entry to place its image into the conversation.
  • For Place entries, use Set Background to apply that image as the current chat background.
  • Type /show Name in the input box to invoke a saved entry by name or alias. Typing /show by itself opens the library.
  • Use /show chat:Name, /show campaign:Name, or /show global:Name to limit the search scope.

Notes

  • URL-imported images are downloaded and stored locally using Tavo's file storage.
  • ImgBB viewing-page links such as https://ibb.co/... are now supported. The plugin will attempt to extract the real i.ibb.co/... image automatically.
  • Tavo currently does not expose the Android photo-library/file picker to plugins, so imports begin from a URL.
  • This Chat entries stay with the current chat. Campaign entries follow one campaign across sessions without appearing in unrelated campaigns. Global entries can be reused everywhere.
  • When StoryState is installed, Visual Library automatically uses StoryState's current campaign ID. Without StoryState, create or select a campaign in the Library tab.
  • Copy This Chat → Campaign safely duplicates chat-scoped images into the current campaign library; the original chat entries are left untouched.
  • The plugin shows images in chat by appending an assistant-side visual bubble.
  • If multiple entries match a /show query, the plugin will ask you to be more specific.
  • Place backgrounds: use the opacity slider in the library and the Restore Theme Background button to return to your normal theme.
  • Place backgrounds work more reliably with Source URL — recommended. Local Tavo copy — experimental may render black in the current Tavo app.
  • Smart Invocation: in the plugin settings, you can optionally auto-show characters, places, or both when the narrator mentions a saved name/alias. It is off by default and includes a repeat cooldown.
